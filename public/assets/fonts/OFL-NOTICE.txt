Self-hosted webfonts for druzzal.com
====================================

released under the SIL Open Font License, Version 1.1. Self-hosting and
redistribution are permitted under that licence; this notice accompanies the
files as the licence requires.

Provenance
----------
These are the same binaries the site previously loaded from
fonts.gstatic.com, fetched by tools/fetch-fonts.py using the identical css2
request the pages used to make. Keeping the source identical is deliberate: a
different build of Fraunces (for example one that still exposes the SOFT and
WONK axes) would render the headings slightly differently from production.

Do not overwrite a file in place. /assets/fonts/* is served with a one-year
immutable cache, exactly like /assets/images/*, so a replacement face needs a
new filename and a matching update to the @font-face src in
/assets/css/main.css and to the preload links in every page head.
